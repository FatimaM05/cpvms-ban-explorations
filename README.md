# FYP Explorations

This repository is dedicated to tracking all research and preparatory work for my Final Year Project (FYP): **Central Pediatric Vital Monitoring System (CPVMS)** for **Body Area Networks (BAN)**.

> **Note:** This repo is **not** the final project itself. It only contains:  
> - Hardware choices and experiments  
> - Software techniques to be used  
> - Dataset collection and dummy datasets  
> - Any research, notes, or trial experiments  
> - Tracking of all the steps I am doing and how much effort each part takes 

The final project will be a **web-based system**, but this repository serves as a workspace to **document, explore, and track all the steps leading up to the main project**.
